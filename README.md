# TaskFlow Frontend

React app for TaskFlow, a role-based task management app.
Built as the companion project for the MERN stack course on La Excellence.

**Backend repo:** https://github.com/<your-username>/taskflow-backend

## Course progress tags

- `module-0-complete` - repo and folder structure set up
- `module-4-complete` - React foundation and auth flow done
- `module-5-complete` - admin and user dashboards done
- `module-6-complete` - deployed live on Vercel

To jump to a module's starting point:
```
git checkout module-4-complete
```

## Setup

1. `npm install`
2. `npm start`

Make sure the backend (taskflow-backend) is running, this app calls its API.
